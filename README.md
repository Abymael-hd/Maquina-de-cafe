# ☕ Máquina de Café com Arduino

Simulação de uma máquina de café automatizada desenvolvida no Tinkercad utilizando Arduino.

---

## 📖 Sobre o Projeto

Este projeto simula o funcionamento de uma máquina de café, onde o usuário interage através de botões para iniciar o preparo. O sistema utiliza lógica embarcada para controlar o fluxo do processo, representando cada etapa com sinais visuais.

---

## ⚙️ Funcionalidades

- 🎛️ Acionamento por botões
- 💡 Indicação de estados com LEDs
- 🔄 Lógica de funcionamento automatizada
- 🧠 Controle via Arduino

---

## 🛠️ Tecnologias

- Arduino UNO  
- Linguagem C/C++ (Arduino)  
- Tinkercad Circuits  

---

## 🎯 Objetivo

Aplicar conceitos de:
- Sistemas embarcados  
- Lógica de programação  
- Automação básica  

---

## 📚 Aprendizados

- Manipulação de entradas e saídas digitais  
- Uso de estruturas condicionais (`if`, `switch`)  
- Simulação de circuitos eletrônicos  
- Organização de código em projetos embarcados
